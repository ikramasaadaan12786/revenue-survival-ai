# Revenue Survival AI Agent ⚡

An autonomous multi-agent revenue generation platform built to receive a business mission (e.g. *"Generate AED 1,000 revenue within 72 hours with 0 AED spend"*) and execute the complete **Research → Decide → Execute → Measure → Improve** lifecycle.

---

## 🏛 System Architecture

### Multi-Agent Swarm
1. **Survival Manager Agent (Main Brain)**: Meta-controller that monitors burn rate, time remaining (72-hour countdown), pipeline value, and autonomously triggers **Tactical Pivots** when conversion drops below threshold.
2. **Opportunity Hunter Agent**: Mines buyer intent & pain points across Google Trends, Reddit (`r/dubai`), YouTube comments, and Telegram channels.
3. **Offer Creator Agent**: Formulates high-converting commercial offers, sales messages, landing copy blueprints, and objection-handling FAQs.
4. **Lead Hunter Agent**: Discovers prospects and scores them into **Cold, Warm, Qualified, and Hot** intent categories.
5. **Outreach Agent**: Generates ultra-personalized WhatsApp scripts, emails, and LinkedIn InMails with built-in **Human-in-the-Loop Safety Approvals**.
6. **Sales Assistant Agent**: Handles prospect questions, resolves objections, qualifies budget, and schedules closing calls.
7. **Dubai Real Estate Revenue Specialist Mode**: Tailored for high-ticket UAE opportunities—off-plan distressed deals, buyer profile matchmaking, and investor ROI calculation models.

## 🚀 Quick Start Guide

### 1. Start the FastAPI Backend
```bash
# From workspace root
python backend/seed.py      # Initialize & seed the 72-Hour mission
python backend/run.py       # Starts API server on http://localhost:8000
```

### 2. Start the Next.js Frontend
```bash
cd frontend
npm install
npm run dev                 # Starts Dashboard on http://localhost:3000
```

## 🛡 Human-in-the-Loop Safety Protocol
All outbound pitches generated by the autonomous outreach agent are placed into the **Safety Approval Queue**. Operators have 1-click controls to:
- **Approve & Dispatch**
- **Inline Edit & Approve**
- **Reject Pitch**
- **Simulate Customer Replies** to test the objection-handling sales agent and survival pivot triggers.
